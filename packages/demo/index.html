Velkren

The same renderer-neutral core, exercising the mechanisms below, running unchanged on three adapters — SolidJS, React, and Vue.

Two editors

Two isolated editors, each a Panel with a text field and a button. Click a button in any editor; only that editor's own event appears in the activity log.

Native nested views

A registered native "Dialog" view exposes a named anchor. "Mount child" projects an independent, Velkren-managed child into that anchor via mountChild — its own identity and interaction capture, isolated from the dialog's own chrome.

Keyed list reordering

Type into any row, then click Shuffle. The row's DOM element (and whatever you typed) follows its key instead of staying at its old position.

Membrane embedding

The three widgets below are plain custom elements, placed as ordinary static markup on this page — no JS-driven mount call runs for them specifically. Each mints its own Velkren runtime the instant it's placed.
